# § 2-1. Tiltaksverdier

**Kilde:** Forskrift om tiltaksverdier og grenseverdier for fysiske og kjemiske faktorer i arbeidsmiljøet samt smitterisikogrupper for biologiske faktorer (forskrift om tiltaks- og grenseverdier) § 2-1

**1. ledd**

Tiltaksverdiene for støyeksponering er:

|  | a) | nedre tiltaksverdi for arbeidsforhold i gruppe I: | L EX,1h = 55 dB |
|---|---|---|---|
|  | b) | nedre tiltaksverdi for arbeidsforhold i gruppe II: | L EX,1h = 70 dB |
|  | c) | nedre tiltaksverdi for arbeidsforhold i gruppe III: | L EX,8h = 80 dB |
|  | d) | øvre tiltaksverdier: | L EX,8h = 85 dB og L pC,peak = 130 dB |


**2. ledd**

For arbeidsforhold i gruppene I og II skal støy fra egen aktivitet ikke inngå i vurderingen i forhold til nedre tiltaksverdi såfremt arbeidstakeren kan avbryte støyen. For spise- og hvilerom skal kun bakgrunnsstøy fra installasjoner, tilstøtende lokaler og omgivelser inngå i vurderingen.
