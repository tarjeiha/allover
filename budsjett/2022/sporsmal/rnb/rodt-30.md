# Spørsmål nr. 30 fra Rødt til RNB 2022

- **Parti:** Rødt
- **Spørsmålsnr:** 30
- **Dato på spørsmålet:** 13.05.2022
- **Kategori:** Norsk økonomi
- **Kapittel og post:** 2670.70
- **Departement:** AID
- **Tittel:** Svar på spørsmål 30 fra Finanskomiteen/Rødts fraksjon av 13.5.2022

## Pensjon - andel av personene som fyller 62 år i år eller i 2021 som har rett til å ta ut alderspensjon fra NAV fra måneden etter de har bursdag

Hvor stor andel av personene som fyller 62 år i år eller i 2021 har rett til å ta ut alderspensjon fra NAV fra måneden etter de har bursdag? Ber om tall for hele kullet og for gruppen som ikke har rett på AFP.

## Svar

Spørsmålet er forelagt Arbeids- og inkluderingsdepartementet, som har gitt følgende svar:

«Arbeids- og inkluderingsdepartementet har fått Arbeids- og velferdsdirektoratet til å anslå hvor stor andel av personene født 1960 som oppfylte vilkåret for uttak av 100 prosent alderspensjon fra 62 år (dvs i 2022), jf. tabell 1.

Tabell 1. Andel født 1960 som oppfylte vilkåret for uttak av 100 prosent alderspensjon ved 62 år i 2022, etter sektor/AFP-rett per desember 2021

| Gruppe |  | Andel |
|---|---|---|
| Hele årskullet, ekskl. personer som allerede mottar andre ytelser som ikke kan kombineres med alderspensjon* |  | 58 % |
| Herav personer uten rett til verken privat eller offentlig AFP** |  | 48 % |
| Mer detaljert inndeling (gjensidig utelukkende kategorier): |  |  |
| Privat sektor med AFP |  | 92 % |
| Privat sektor uten AFP |  | 61 % |
| Offentlig sektor |  | 37 % |
| Selvstendig næringsdrivende |  | 45 % |
| Ikke-yrkesaktive |  | 27 % |
| * Gjelder uføretrygd, gjenlevendepensjon. |  |  |
| ** Gjelder kategoriene Privat sektor uten AFP, Selvstendig næringsdrivende og Ikke-yrkesaktive. |  |  |

Tallene gjelder personer bosatt i Norge ved utgangen av 2021, fordelt etter hvilken sektor de da var yrkesaktiv i. Personer som på dette tidspunktet mottok uføretrygd eller etterlattepensjon inngår ikke i tallene (verken i teller eller nevner), siden mottakere av disse ytelsene ikke kan ta ut 100 prosent alderspensjon i kombinasjon med uføretrygd/etterlattepensjon, og at de kan fortsette å motta disse ytelsene fram til overgang til alderspensjon ved 67 år. Merk at andelene for offentlig sektor gjelder for uttak av alderspensjon. Offentlig ansatte vil i stedet for alderspensjon kunne ta ut offentlig AFP (forutsatt at de oppfyller de individuelle vilkårene for AFP).»
