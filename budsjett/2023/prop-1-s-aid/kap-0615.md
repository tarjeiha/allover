# Kap. 615 Yrkesskadeforsikring

|  |  |  |  | (i 1 000 kr) |
|---|---|---|---|---|
| Post | Betegnelse | Regnskap 2021 | Saldert budsjett 2022 | Forslag 2023 |
| 01 | Driftsutgifter, overslagsbevilgning | 96 642 |  |  |
|  | Sum kap. 615 | 96 642 |  |  |

Med virkning fra 2022 ble budsjettansvaret for kap. 615 Yrkesskadeforsikring overført til Kommunal- og distriktsdepartementet som er ansvarlig departement for ordningen.

Som følge av dette fremgår forslag om bevilgning for 2023 av Kommunal- og distriktsdepartementets Prop. 1 S for 2023 under kap. 506. Rapporteringen for 2021 er omtalt samme sted.
