# Spørsmål nr. 135 fra H til STB 2025

- **Parti:** H
- **Spørsmålsnr:** 135
- **Dato på spørsmålet:** 15.10.2024
- **Kapittel og post:** D.
- **Departement:** AID
- **Tittel:** Svar på spørsmål 135 fra Finanskomiteen/Hs fraksjon av 15.10.2024

## Lønnsgarantiordningen - gjennomsnittlige saksbehandlingstiden for lønnsgarantiordningen per år de siste ti årene

Hva er den gjennomsnittlige saksbehandlingstiden for lønnsgarantiordningen per år de siste ti årene?

## Svar

Spørsmålet er forelagt Arbeids- og inkluderingsdepartementet, som har gitt følgende svar:

«Arbeids- og velferdsetaten har av tekniske årsaker ikke tilgjengelige tall for gjennomsnittlig saksbehandlingstid i lønnsgarantiordningen. Etaten har tilgjengelige tall fra manuell rapportering på andel søknader som er behandlet innen to måneder. Tall i tabellen under er forholdstall mellom hva som er behandlet innen to måneder og hva som er behandlet senere enn to måneder.

| År | Andel søknader behandlet innen to måneder |
|---|---|
| 2015 | 74 % |
| 2016 | 80 % |
| 2017 | 74 % |
| 2018 | 76 % |
| 2019 | 79 % |
| 2020 | 82 % |
| 2021 | 79 % |
| 2022 | 81 % |
| 2023 | 88 % |
| 2024* | 84 % |

*januar til september

»
