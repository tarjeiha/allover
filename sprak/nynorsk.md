# Føringer for nynorsk (grammatikk)

Gjelder all nynorsk tekst fra departementet. Kilde: veilederen (se `VEIVISER.md`). Ordvalg står i `ordliste.md`, bøying av enkeltverb i `verbboying.md`.

Grunnregel: der nynorsk har flere gyldige alternativer, velg formen som
ligger nærmest bokmål.

## Ikke j der det er valgfritt
Skriv **uten** j når begge former finnes:

| Bruk | Ikke bruk |
| --- | --- |
| ei brygge | ei bryggje |
| ei bølge | ei bølgje |
| å ligge | å liggje |
| ifølge | ifølgje |
| fremme | fremje |

NB: Autokorrektur kan sette inn j-formen automatisk — sjekk.

## Dobbel konsonant der det er mulig
Velg dobbel konsonant framfor enkel: **lønn** (ikke løn), **kjøkken**
(ikke kjøken), **komme** (ikke kome), osv.

## Valgfri vokal — velg formen nærmest bokmål
Bruk *fore-* (ikke *føre-*), ø (ikke y), o (ikke u) der det er valgfritt:

| Bruk | Ikke bruk |
| --- | --- |
| formål | føremål |
| bustøtte | bustønad |
| skole | skule |
| ønske | ynske |
| forprosjekt | føreprosjekt |
| forarbeid | førearbeid |
| først | fyrst |
| nøkkel | nykel |
| følge | fylgje |
| lykke | lukke |

## Unngå passiv
Skriv mest mulig direkte. I stedet for *«Det blir bede om synspunkt på
forslaget frå høyringsinstansane»*, skriv *«Vi ber høyringsinstansane om
synspunkt på forslaget».*

Må vi likevel skrive passivt:
- **Aldri** st-form alene i setningen. Ikke *«Søknaden innvilgast»* — skriv
  *«Søknaden kan innvilgast».*
- Bruk alltid modalt hjelpeverb (kan, skal, bør, må …) foran st-formen.
- Vanlig passiv kan også lages med *blir* + verb: *«Ytinga blir innvilga
  inntil eitt år om gongen.»*
- Ved omsetting til nynorsk er omskriving ofte enkleste vei bort fra passiv.

## Dobbel bestemmelse (som i talespråket)

| Enkel bestemmelse | Dobbel bestemmelse |
| --- | --- |
| denne sak | denne sak**a** |
| denne type | denne type**n** |
| dette brev | dette brev**et** |

## Etterstilt eiendomsord
Ikke skriv: *Hennar lønn i perioden utgjorde (…)*
Skriv: *Lønna hennar i perioden utgjorde (…)*

Ikke skriv: *Vi viser til deres høyringsbrev om (…)*
Skriv: *Vi viser til høyringsbrevet dykkar om (…)*

## Genitiv og genitivsuttrykk
Tre måter å uttrykke genitiv/egenform på:

**S-genitiv** — ved egennavn (*Barne- og familiedepartementet,
Noregs lover*) og enkelte faste tids-/måluttrykk (*fem ukers ferie, til
fots, dagens avis*).

**Sin-genitiv** — ved rene eierforhold (*Ida sin PC, sjefen sitt kontor*)
og ved personer/institusjoner (*Regjeringa si offisielle haldning,
direktoratet sitt budsjett, FN sine bærekraftsmål*). **Skal ikke**
brukes ved ting og abstrakte begrep (ikke *«helga sin sport»*).

**Omskriving** (når sin-genitiv ikke skal brukes) — med preposisjon,
sammensetning eller leddsetning:

| Bokmål | Nynorsk (preposisjon) |
| --- | --- |
| Lovens krav | Krava i lova |
| Kursets formål | Formålet med kurset |
| Direktoratets brev | Brevet frå direktoratet |

| Bokmål | Nynorsk (sammensetning) |
| --- | --- |
| Prosjektets administrasjon | Prosjektadministrasjonen |
| Avdelingens sjef | Avdelingssjefen |
| Årets budsjett | 2023-budsjettet |

| Bokmål | Nynorsk (leddsetning) |
| --- | --- |
| Forskningens rolle i samfunnet | Den rolla forskninga har i samfunnet |
| Reformens betydning for den enkelte | Kva reforma inneber for den enkelte |

## Verb — generelle regler
- **E-infinitiv**: bruk e-verb der et verb har flere bøyingsformer, f.eks.
  *å bruke*: bruke–bruker–brukte–brukt (ikke bruke–brukar–bruka–bruka).
  Se `verbboying.md` for en full liste over interne føringer per verb.
- **Unngå substantivering**: foretrekk verbale uttrykk. Ikke *«… bør ein
  foreta ein gjennomgang av dei malar …»* — skriv *«… bør ein gå gjennom
  malane …»*.
- **Løst sammensatte verb**: verb + preposisjon/adverb skrives hver for seg
  og bøyes ut fra grunnformen, f.eks. *framlegge* → *å legge fram*. **Men**
  etter er/blir/(vert) skal verbet skrives sammensatt: *blir framlagd*.
  Andre løse sammensetninger:

  | Skriv på nynorsk | Bokmålsordet (ikke bruk på nynorsk) |
  | --- | --- |
  | ta imot | motta |
  | høyre til | tilhøre |
  | ligge føre | foreligge |
  | svare til | tilsvare |
  | skrive under | underskrive |
  | skrive ut | utskrive |
  | føre vidare | videreføre |

- **Å vere, ikke å være**: *å være* har en annen betydning på nynorsk.

## Substantiv
- **Ikke nakne substantiv**: bruk bestemt form der det er naturlig. Ikke
  *«Dersom søkar har gjennomført liknande tiltak …»* — skriv *«Dersom
  søkaren har gjennomført liknande tiltak …»*.
- **Ikke bruk *den*** for hankjønn/hunkjønn — bruk **han**/**ho**.
- **Kjønnsbestemmelse** — nynorsk har tre kjønn (hankjønn *ein*, hunkjønn
  *ei*, intetkjønn *eit*), og substantiv bøyes i både kjønn og antall:
  - Endinger **-ar/-ane**: de fleste hankjønnsord + hunkjønnsord på
    *-ing*/*-ning*.
  - Endinger **-er/-ene**: de fleste hunkjønnsord.
  - Endinger **-∅/-a**: nesten alle intetkjønnsord.
  - Hankjønn (*ein*) som hovedregel: biologisk maskuline ord (*ein mann, ein
    konge*), generelle personord (*ein psykolog, ein president, ein lærar*),
    ord på *-dom, -ikk, -isme, -itet, -leik, -nad, -sjon*.
  - Hunkjønn (*ei*) som hovedregel: biologisk feminine ord (*ei jente, ei
    tante*), ord på *-ing*.
  - Intetkjønn (*eit*) som hovedregel: mange stoff- og materialeord (*eit
    metall, gull, sølv, salt, sukker, kjøt, vatn* osv. – full liste i
    `ordliste.md`), ord på *-drag, -eri, -fall, -gram, -grep, -hald, -legg,
    -løp, -ment, -mål, -tak, -tek, -tiv, -um*.
  - **Midel** (hankjønn, om penger: *offentlege midlar*) vs. **middel**
    (intetkjønn, om hjelpemiddel: *hjelpemiddel, næringsmiddel*).

## Hvor/hvilken → kor/kvar/der og kva
- **Hvor**: i relativsetninger, bruk **der** (der bokmål kan velge mellom
  *hvor*/*der*). Ved sted: **kor**/**kvar** (*kor/kvar ligg
  hovudkontoret?*). Ved grad: **kor** (*kor stor innsats må til?*).
- **Hvilken/hvilke/hvilket** → **kva**, **kva for**, **kva for
  ein/ei/eit/nokre**: *om kva typar tiltak*, *om kva for typar tiltak*,
  *om kva for nokre typar tiltak*, *om kva slags typar tiltak*.

## Man → ein
Skriv **ein**, ikke *man*. Ofte bedre å bytte ut med ordet det viser til:
*«Ved andre statsorgan har ein heilt andre rutinar»* → *«… har dei heilt
andre rutinar.»*

## Noen → nokon/nokre
- **Nokon** (jf. eng. *any*): ved spørsmål, tvil, nekting. *Var det nokon
  på kontoret? Det var ikkje nokon på kontoret. Det var neppe nokon på
  kontoret.* Bøyes: *nokon* (hankjønn), *noka* (hunkjønn), *noko*
  (intetkjønn), *nokre* (flertall).
- **Nokre** (jf. eng. *some*): uten tvil flertall. *Det var berre nokre
  få på kontoret.*

## Enhver → alle / kven som helst / kvar (ein)
*til enhver tid* → *til kvar tid, alltid, når som helst, heile tida.*

## Endinger på -ing/-ning
Der begge er valgfrie, bruk **-ning**: *forvaltning*, *belastning*.
Står ordet i `ordliste.md`, gjelder ordlista: *forsking, satsing, avkorting,
tilråding, verdiskaping* (ikke -ning). Se «Uavklart i veilederen» i `VEIVISER.md`.
